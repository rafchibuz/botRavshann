# Ravshan Twitch Bot

Веб-панель и чат-бот для каналов RavshanN. Панель умеет создавать, редактировать,
включать и удалять таймеры, хранить заготовки закреплённых сообщений и отвечать на
`!актив` с местом зрителя в рейтинге.

## Локальный запуск

1. Скопируйте `config.example.json` в `config.json` и заполните секреты.
2. Запустите `docker compose up --build`.
3. Откройте `http://localhost:8080`.

`config.json` исключён из Git, чтобы OAuth-токен и пароль панели не попали в репозиторий.

## Команда `!актив`

Бот отвечает не чаще одного раза за `activity.cooldownSeconds` (по умолчанию 10 секунд).
Если несколько зрителей пишут команду во время паузы, ответ получает последний.

Публичный endpoint `https://www.ravshan.tv/api/rating?channel=all&period=1y` сейчас
возвращает только топ-100. Для точного места любого зрителя укажите `activity.lookupUrl`.
Поддерживаются два варианта:

- шаблон: `https://ravshan.tv/api/rating/lookup?login={login}&channel=all&period=1y`;
- обычный URL: бот сам добавит параметры `login`, `channel=all`, `period=1y`.

Ожидаемый ответ endpoint:

```json
{"data":{"rank":123,"login":"viewer_login"}}
```

До появления lookup-endpoint бот использует публичный топ-100 и явно сообщает, когда
точное место недоступно.

## Закрепы Twitch

Настоящий закреп выполняется через Twitch Helix `PUT /helix/chat/pins`. В `config.json`
нужен `twitch.clientId`, а OAuth-токен аккаунта бота должен иметь scope
`moderator:manage:chat_messages`. Аккаунт бота должен быть модератором канала.
Минимальный срок закрепа — 30 секунд, максимальный — 1800.

## Чат-команды

- `!актив` / `!active` — место автора команды в рейтинге;
- `!пинг` / `!ping` — аптайм;
- `!таймер` — статус таймеров;
- `!таймер <id или название>` — включить таймер (модератор/стример);
- `!таймерофф <id или название>` и `!таймерофф все` — выключить;
- `!таймеры старт` / `!таймеры стоп` — запустить или остановить цикл.
